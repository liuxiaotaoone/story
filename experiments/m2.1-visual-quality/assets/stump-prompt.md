# Stump Prop Prompt

Built-in imagegen, using `experiments/asset-feasibility/processed/environment/mid.png` as the style reference.

Create one compact old cut tree stump for a running rabbit to collide with. Match the rural watercolor paper-cut environment: warm ochre-brown bark, visible growth rings, small root flare, crisp cream paper edge. Center the full prop with generous padding on a perfectly flat `#ff00ff` chroma-key background. No characters, leaves, branches, shadow, text or watermark; do not use the key color in the subject.

`stump.png` was produced from `stump-chroma.png` with the imagegen skill's `remove_chroma_key.py` helper using border auto-key, soft matte and despill.
