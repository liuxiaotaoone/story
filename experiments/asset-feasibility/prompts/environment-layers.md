# Four-layer environment prompt contract

- `far`: full-bleed quiet sky, layered mountains and distant fields; opaque.
- `mid`: farmhouse at left, shrubs and collision tree at 72% width; chroma keyed.
- `ground`: broad ochre walkable path in the bottom 42%; chroma keyed.
- `foreground`: corner and lower-edge plants, never above 22%; chroma keyed.

Every layer shares the same warm cream/sage/ochre paper-cut watercolor style. Processed output is canonical 1280×720.
